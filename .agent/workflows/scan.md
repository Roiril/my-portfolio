# /scan（調査専用 / Read-only）

あなたは調査担当です。/scan の後ろに書かれた依頼文を要件として扱い、関係ファイルの特定と該当箇所の提示だけを行ってください。

## Hard rules（必ず守る）
- 変更を一切しない（ファイル作成・編集・整形・自動修正をしない）
- 差分方針・実装手順・修正案を出さない（どう直すかは書かない）
- 推測で断言しない（関連だと言うなら、参照元や import の根拠を添える）

## 調査でやること
1) 入口を特定する（app の route/page/layout）
2) 参照をたどって関係ファイルを絞る（app → features → components/lib/content）
3) 単一の正を特定する（作品データ、設定、型など）
4) ChatGPT が判断できる該当箇所を提示する（抜粋 or 行番号）

## 優先して抜く該当箇所
作品追加・機能追加系なら次の順で優先する
1) 作品データの正（配列、frontmatter 例、スキーマ）
2) 一覧ページの入口（どこから読んでいるか）
3) 型定義（必須フィールド、制約）
4) カード/詳細表示（表示に必要なフィールド）
5) 画像参照規約（public 参照か import か）

## 出力に関する制約（重要）
- 抜粋は必要最小限
- 1ファイルあたり最大25行、最大5ファイルまで
- 行番号が取れるなら Lx-Ly を併記する
- 行番号が取れない場合は、該当箇所が特定できるユニークな数行と前後を抜粋する

## 許可する操作（Read-only）
- 読み取りのみ（例：ls, cat, sed -n, rg, git grep, git show）
- 書き込み・生成・フォーマット系は使わない

## Output format（この見出しのまま出力）
### Related files tree
- 関係ファイルだけを tree で出す（全体 tree は不要）
- 各行に短い注釈（最大12語、役割と注目ポイント）

### Key notes for ChatGPT
- 最大10行の箇条書き
- 1行は「パス / 役割 / 根拠（どこから参照）」の順

### Relevant excerpts (quoted)
- 最大5ファイルまで
- 各ファイル：
  - path + 行番号範囲（可能なら）
  - 何が分かる抜粋かを1行で説明
  - 抜粋（最大25行）

### Commands
- 実行したコマンドがあれば列挙し結果を書く
- 何も実行していない場合は必ず次の1行だけを書く：
No commands run.
